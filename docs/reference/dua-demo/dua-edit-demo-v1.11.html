Dua edit screen — demo v1.11 J104 · D03 + D05

For the Owner. Nothing here is saved anywhere; it only shows how it would look and behave. Press Menu on the Dua card and choose the Edit tab.

What this adds

1. A title in English and Bangla for any Dua (D05). 2. Put a Dua in one group or several — the Dua stays one Dua; your marks, notes and bookmark follow it everywhere (D03). 3. "Delete" means Hide: a hidden Dua is kept and can be brought back (never destroyed). 4. Add a new Dua of your own text.

Only the owner and prime see the Edit tab. A student sees the Menu exactly as today.

What happens behind the scenes (plain words)

Each Dua you change gets one small note that says: its title, which groups it is in, and whether it is hidden. Nothing else is touched, so everyone's progress, notes and bookmarks stay safe. When a group is deleted in the groups pop-up, the Dua simply stops showing in it; it is never lost.
