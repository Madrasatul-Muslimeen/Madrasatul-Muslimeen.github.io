# ADR-003 — Separate Activity from Mastery

- **Status:** ACCEPTED
- **Date:** 2026-09-10
- **Context:** Reading, listening, opening, clicking, and logging are evidence of activity but do not necessarily prove competence.
- **Decision:** **Activity ≠ Mastery.** Raw activity and derived/confirmed progress remain separate. No interaction automatically grants mastery unless an accepted rule contract explicitly defines that transition.
- **Alternatives considered:** infer mastery from any activity; store only a final status.
- **Consequences:** Stage 3 sequencing must require a versioned mapping/confirmation rule before automatic Approach progress behavior.
- **Affected requirements:** MAP §§1,3,20 Phases 3–4,22.
- **Supersession:** none.
