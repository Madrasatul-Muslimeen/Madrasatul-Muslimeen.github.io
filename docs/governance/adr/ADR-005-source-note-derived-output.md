# ADR-005 — Protect Source Notes from Derived Output

- **Status:** ACCEPTED
- **Date:** 2026-09-10
- **Context:** Dawah may transform Note material into Share/media outputs.
- **Decision:** Dawah is broader than Share. Every Dawah/Share artifact is derived output and must never overwrite its source Note.
- **Alternatives considered:** edit the Note in place for publishing; treat Share as the full Dawah domain.
- **Consequences:** source provenance and immutable linkage are prerequisites for Dawah/Share implementation.
- **Affected requirements:** MAP §§1,3,20 Phases 7–8,22.
- **Supersession:** none.
