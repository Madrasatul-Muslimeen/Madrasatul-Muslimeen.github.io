- **A baseline is cheaper than a guess:** `git worktree add $S/base HEAD`, symlink `tools/i18n-verify/node_modules` to `/opt/node-tools/node_modules`, `PORT=8081 node serve.js` there, run the same suite with `QR_BASE=http://localhost:8081`. Remove the worktree after (`git worktree remove --force`).
- **A suite that crashes early hides what is behind it** (global-approach-card on main). When a rewritten route lets it run, its first full run is where its hidden failures show: report them, do not fold them into your round.
- **A hidden control is not unreachable only in CSS you wrote:** the bare full-screen rule `#readBarEnd > *:not(...) { display:none }` silently hid the new ⋮; the rewritten read-quick-buttons suite caught it (the ⋮ measured 0 wide). Whenever a control MOVES into a menu, walk every state where that menu's button is hidden.
- A mutation can be UNPROVEN because two rules do one job (`pillback` at 390: the phone rule also hid the pill). Run it where only the rule under test applies.
- Foreground commands over 120 s are moved to the background by the harness; start long suites with `nohup … &` and poll with sleeps under 110 s. `get_session` `context_usage` read 0 for this whole session: judge by the work done.
- Never `selectOption` a hidden picker: set `.value` and dispatch `change` (bubbles) in `page.evaluate`, or use the sheet's mirror.
- `behaviour.mjs` takes about 20 minutes; run it once at the end.
