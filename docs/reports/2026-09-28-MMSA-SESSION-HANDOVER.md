## 3. How to start and review a Builder round — hard-won this session

- **Start a round ONLY with `workflow_dispatch`**: `mcp__github__actions_run_trigger`,
  `method: run_workflow`, `workflow_id: claude.yml`, `ref: main`,
  `inputs: { issue_number, note }`.
  - **Never with a comment.** `claude.yml`'s `if:` refuses any comment containing
    "Generated by [Claude Code]". Every Architect comment must carry that footer,
    so an Architect's comment can never start the Builder. #342 lost 90 minutes
    to this (run 547, `skipped`).
  - The **unattended** Architect (`architect.yml`) cannot dispatch at all
    (HTTP 403): the repository's Settings → Actions → General → "Workflow
    permissions" is read-only. A session Architect's dispatch works, because the
    MCP tool acts as the Owner.
- **Tell the Builder to push early.** Every dispatch note must say: create the
  branch and push within the first 10 turns, push after every part, and open the
  PR as soon as part 1 is pushed. A run can "succeed" and push nothing (#342's
  first run).
- **The Builder often opens no pull request.** Find its branch:
  ```
  git fetch origin '+refs/heads/*:refs/remotes/origin/*'
  git for-each-ref --sort=-committerdate refs/remotes/origin | head
  ```
  Look for `claude/issue-N-*`. Merge current `main` into it on your own branch,
  review, fix, allocate, then open and merge the PR yourself.
- **Review by measurement**, every round:
  - the round's own suite;
  - `layout.mjs`, `phone-width-overflow`, `behaviour.mjs`;
  - the 8 CI-gated governance suites;
  - both languages;
  - screenshots, **looked at**;
  - mutation proofs.
- **Expected numbers must never be computed by the function under test.** #341's
  suite did exactly that (`summarizeUnitCoverage()` on both sides). Count
  independently and compare with Explore's own list (`chip-<status>`).
- **Allocate** with `python3 tools/governance/allocate-version.py …` (see its
  header). Before the merge, exactly `brief-integrity`, `programme-ledger` and
  `programme-ledger-mutations` fail, because they read `origin/main`. After the
  merge all three must pass.
