## Lessons (new this segment)
- **A mutation regex must consume to the end of the line.** My first `PRINTED-EXCLUDED` mutants removed only the marker and left the rest of the comment, a syntax error: the worker never installed and the test HUNG (it did not fail by name). That looked like a flaky suite for an hour. Give every worker/page check a bounded wait that fails by name (`serviceWorker.ready` raced with a 20s timer), and make probes null-safe so a mutant ends in a named FAIL, not a throw.
- **The QR half of a worker test runs against `build/qr`**, so a mutation of QR's source needs a rebuild first, and a mutant build left behind poisons the next run: rebuild clean (`node tools/apps/build-app.mjs qr`) before reading a result.
- **Count visible elements, not DOM elements**: the Mushaf strip keeps its last drawing hidden when the reader leaves, so `querySelectorAll(".mushaf-printed-page").length` stayed 1 after the 3rd press. Filter on `getClientRects().length`.
- **A third stop in a cycle breaks every suite that presses the button N times.** Grep `readMeaningBtn` across `tools/i18n-verify` before changing the cycle (I updated four: `read-on-switch`, `read-meaning`, `read-mushaf-button`, `qr-j110-reading-view`).
- **Baseline before blaming** (handover 17) paid off again: `read-mushaf-button` "adds no line" 193 vs 146 and `ayah-step-all-views` [360] are red on clean `main` too. `git worktree add --detach /tmp/x origin/main`, `PORT=8081 node serve.js` there, `QR_BASE=http://localhost:8081`. Remove the worktree and kill that server afterwards.
- Never `send_message` with a guessed session id: I sent one stray "placeholder" message to my own session by mistake. Get ids from `list_sessions`.
