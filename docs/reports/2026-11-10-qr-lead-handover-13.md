## Lessons this session
- **A retired control is gone from the page, not just from sight, for a suite**: `#readNotesBtn`, `#readBookmarkBtn` are `display:none !important` (J114) and the harness `legacyTools` only restores ⋯ and its menu, NOT those two. Probe the rendered state (`getBoundingClientRect`, ancestors' display) before assuming a click timeout is a timing problem.
- **A finger-size detector must judge where scrolling puts a control**, with every scroll put back; a control under the fixed dock is only below the fold. Controls for both directions (clears / cannot scroll) are the proof, with a mutation for each half.
- **A before/after on the same suite IS a mutation proof for an app fix** (14/2 before, 16/0 after), but only when the "before" is run on the same tree minus the fix.
- **The ⋮ sheet's Notes tile is "Take Note"** when the āyah has no Note, and it creates the Note.
- `ArtifactData update` on `p/mmsa` with `file_path` of `{"manual": [...]}` replaces the whole manual array: re-`get` first, edit the list, pin `if_version`. Fields AT THE TOP LEVEL for jobs too.
- `get_session` `context_usage` can be stale (it did not move for hours here): do not trust it as the only signal; hand over by judgement as well.
- The Primary working directory can move when a command `cd`s into a subfolder: always `cd /home/user/Madrasatul-Muslimeen.github.io` first.
