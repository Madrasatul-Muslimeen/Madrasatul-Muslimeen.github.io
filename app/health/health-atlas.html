Health Atlas — foundation (draft)

An MMSA-internal review screen for the Health Atlas v02.04 source handover. Standalone in the sense the rest of this app already is — no sign-in, no tenant, no backend, nothing persisted; it only reads the dataset shipped beside it. Like every other page under app/, its ES module imports need it served over http (see serve.js), not opened as a bare file:// path. It is not linked from the shared navigation.
