Health Atlas — Body Systems (draft, read-only)

An MMSA-internal review screen for the Health Atlas v02.04 source handover: the same three-column layout (drag the strips either side of the wheel to resize it, or focus a strip and use the arrow keys), collapsible system list, interactive systems/organs wheel and body-system diagrams as the source app, over the same preserved dataset. Standalone in the sense the rest of this app already is — no sign-in, no tenant, no backend, nothing persisted; it only reads the dataset shipped beside it. Like every other page under app/, its ES module imports need it served over http (see serve.js), not opened as a bare file:// path. It is not linked from the shared navigation.

Health Atlas Body Systems parity tranche 7 — see app/health/README.md for scope, boundaries and what is deliberately not built yet (system/organ add·edit·delete·reorder, the wheel's third "fields" ring, and header export/import/reset). Source: Health Atlas v02.04 standalone (docs/health-source/health-atlas-v02.04-standalone.html on health/source-v02-04-handover, commit ed4dbb2e).
